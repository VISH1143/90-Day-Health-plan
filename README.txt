90-Day Routine Tracker
========================
This is a mobile-first Progressive Web App (PWA) built around the handwritten routine.

Features:
- 90-day challenge
- One-tap completion tracking
- Daily percentage
- Current streak
- Perfect-day count
- 90-day history heatmap
- Daily reflection/notes
- Start-date control
- Offline caching after the first load
- Installable on Android when served over HTTPS

Important:
The app stores tracking data locally in the browser on the device. If browser data is cleared, local data can be lost.

To install:
1. Host this folder on an HTTPS website (GitHub Pages, Netlify, Vercel, etc.).
2. Open the website in Chrome on Android.
3. Use the browser menu and choose Install app / Add to Home screen.

The app does not require an account or backend.
